📐 หลักการคำนวณความน่าจะเป็นรวมแบบผสม (Mathematical Formula)

เมื่อเปิดกล่องข้ามหลายช่วงเวลาที่มีเรตต่างกัน โอกาสรวมที่จะได้ Pirate Token อย่างน้อย 1 ชิ้น คำนวณจากสูตร Bernoulli:

P(สะสม) = 1 - [ (1 - p₁)^(N₁) × (1 - p₁.₅)^(N₁.₅) × (1 - p₂)^(N₂) ]

หรือหากคำนวณตามเรตดรอปเดี่ยว (1 ใน D) ด้วยจำนวนกล่องรวม N กล่อง:

P(สะสม) = 1 - (1 - 1/D)^N

• เวลาปกติ (1.0x): p₁ = 1 / 137,500
• Treasure Hour 1.5x: p₁.₅ = 1 / 91,667 (หรือ 1.5 / 137,500)
• Treasure Hour 2.0x: p₂ = 1 / 68,750 (หรือ 2.0 / 137,500)
